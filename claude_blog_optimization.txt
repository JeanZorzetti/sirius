You are tasked with implementing the "Blog Optimization Roadmap" to improve SEO and User Experience.

**Context:**
We have 3 high-quality blog posts in `lib/blog-data.ts`. The pages are rendered in `app/(marketing)/blog/[slug]/page.tsx`.
Currently, they lack proper Metadata, Structure Data (Schema), and Engagement features.

**Objectives:**

1.  **SEO: Implement Article Schema (JSON-LD)**
    *   In `app/(marketing)/blog/[slug]/page.tsx`, inject a `<script type="application/ld+json">` tag with `NewsArticle` or `BlogPosting` schema.
    *   Include fields: headline, image, datePublished, author (use "Sirius Team" or specific author), description.

2.  **SEO: Enhance Metadata & Open Graph**
    *   Update `lib/blog-data.ts` to include an `image` property for each post (use a placeholder URL like `/images/blog/pipeline.jpg` if needed, or a generic OG image).
    *   Update `generateMetadata` in `[slug]/page.tsx` to set `openGraph: { images: [...] }`.

3.  **UX: Add "Related Posts" Section**
    *   At the bottom of `[slug]/page.tsx` (after the content), add a section "Leia também" / "Related Posts".
    *   Display 2 other posts from `blogPosts` (exclude current post). Show Title + small Excerpt + Link.

4.  **UX: Add Social Share Buttons**
    *   Add simple buttons (WhatsApp, LinkedIn, Copy Link) below the title or at the end of the article.
    *   WhatsApp link format: `https://wa.me/?text=Check this out: [URL]`

**Files to Modify:**
-   `lib/blog-data.ts` (Add images)
-   `app/(marketing)/blog/[slug]/page.tsx` (Add Schema, OG, Related Posts, Share Buttons)

**Execution:**
Execute the changes directly. Ensure code compiles.
Match the existing design system (Tailwind + Shadcn).
