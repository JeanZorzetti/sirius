3. We define `isSameColumn = activeStage.id === overStage.id`. This evaluates to TRUE even for cross-column moves, because `activeStage` is already the new stage.
4. Consequently, we enter the "Same Column" block, which only calls `reorderDeals` but NEVER calls `updateDealStage`.
5. The deal's `stageId` is never updated in the database.
