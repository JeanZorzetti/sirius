The user wants to add a **WhatsApp Button** to the `EditDealDialog`.

**Context:**
*   `app/dashboard/page.tsx` passes full contact objects (including `phone`) to `KanbanBoard`, but the types in `KanbanBoard` and `EditDealDialog` currently omit `phone`.

**Required Changes:**

1.  **`components/kanban-board.tsx`**:
    *   Update the `Contact` type definition to include `phone?: string | null`.

2.  **`components/deals/edit-deal-dialog.tsx`**:
    *   Update the `EditDealDialogProps` interface: `contacts` should include `phone?: string | null`.
    *   In the component:
        *   Find the currently selected contact object using `selectedContactId` from `localContacts`.
        *   If the selected contact has a `phone` number:
            *   Clean the phone number (remove non-digits).
            *   Display a **WhatsApp Button**.
            *   **Location**: Place it next to the "Quick Add" (+) button, or if space is tight, in a logical place near the Contact field. A green button with a `MessageCircle` icon is good.
            *   **Action**: Clicking opens `https://wa.me/<number>` in a new tab.

**Code Snippet (Reference for Button):**
```tsx
import { MessageCircle } from 'lucide-react'

// ... inside render ...
{selectedContact?.phone && (
    <Button
        type="button"
        variant="outline"
        size="icon"
        className="shrink-0 text-green-600 border-green-200 hover:bg-green-50 hover:text-green-700 dark:border-green-900/50 dark:text-green-400 dark:hover:bg-green-900/20"
        onClick={() => {
             const phone = selectedContact.phone?.replace(/\D/g, '')
             if (phone) window.open(`https://wa.me/${phone}`, '_blank')
        }}
        title="Conversar no WhatsApp"
    >
        <MessageCircle className="w-4 h-4" />
    </Button>
)}
```
